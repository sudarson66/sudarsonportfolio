# Sudarson C — Developer Portfolio

A modern, fully responsive personal portfolio website built with **HTML5, CSS3, and Vanilla JavaScript**.

> **Live Demo:** [View Portfolio](https://sudarson66.github.io/sudarson-portfolio) (update with your GitHub Pages URL)

## 📁 Project Structure

```
sudarson-portfolio/
├── index.html          ← Main HTML file
├── css/
│   └── style.css       ← All styles, animations & responsive design
├── js/
│   └── main.js         ← JavaScript logic (cursor, scroll effects, interactions)
├── README.md           ← This file
├── LICENSE             ← MIT License
└── .gitignore
```

## ✨ Features

- **Smooth Animations** — Left-to-right scroll reveal animations
- **Interactive Elements** — Typewriter effect for role switcher in hero section
- **Custom Cursor** — Animated cursor with ring follow effect
- **Mobile Responsive** — Fully responsive hamburger menu for mobile devices
- **Timeline** — Experience section with timeline layout
- **Project Showcase** — Live project links and descriptions
- **Contact Form** — Form with validation (integrates with backend if needed)
- **Smart Navigation** — Active nav highlighting on scroll
- **Modern Design** — Dark theme with accent colors and glassmorphism effects

## 🚀 Quick Start

### Local Development
```bash
# Clone the repository
git clone https://github.com/sudarson66/sudarson-portfolio.git

# Navigate to project folder
cd sudarson-portfolio

# Open in browser (or use Live Server in VS Code)
open index.html
```

### Deploy on GitHub Pages

1. **Push this repository to GitHub** (replace `your-username`):
   ```bash
   git remote add origin https://github.com/your-username/sudarson-portfolio.git
   git branch -M main
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to **Repository Settings → Pages**
   - Set **Source** to `main` branch, `/ (root)` folder
   - Save

3. **Your site will be live at**:
   ```
   https://your-username.github.io/sudarson-portfolio/
   ```

## 📝 Customization

### Update Personal Info
Edit [index.html](index.html) sections:
- **Hero Section** — Update name, title, and bio
- **About Section** — Add your own content
- **Projects** — Add your projects with links
- **Experience** — Update internships & work history
- **Contact** — Update email and social links

### Modify Colors
Edit CSS variables in [css/style.css](css/style.css):
```css
:root {
  --accent: #00e5ff;      /* Cyan */
  --accent2: #7b61ff;     /* Purple */
  --accent3: #ff6b35;     /* Orange */
  /* ... more colors ... */
}
```
